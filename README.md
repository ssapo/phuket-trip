# 안다만 여행 일정 · 2026.12.18–29

공유받는 사람이 모바일과 데스크톱에서 보는 정적 여행 일정 웹페이지입니다.

## GitHub Pages 배포

1. 여행 전용 저장소를 만들고 `index.html`과 이 문서를 기본 브랜치 루트에 업로드합니다.
2. Settings → Pages → Build and deployment → Source에서 **Deploy from a branch**를 선택합니다.
3. 기본 브랜치와 **/(root)**를 선택하고 Save 합니다.
4. GitHub Pages 배포가 완료되면 Settings → Pages가 표시하는 실제 URL을 공유합니다.

별도의 패키지 설치나 빌드가 없습니다. 기본 브랜치 변경을 저장하면 GitHub Pages가 다시 배포합니다. 배포에는 시간이 걸리므로 변경 즉시 실시간 동기화되는 것은 아닙니다.

## 일정 수정

`index.html`의 `trip-data` JSON과 상단 숙박 요약·예약 체크 항목을 함께 변경하세요. ChatGPT에 변경을 요청해서 커밋하도록 해도 됩니다.

매 수정 시 `trip-version` 메타 값을 새로운 값으로 바꾸고, 하단 업데이트 날짜도 변경하세요. 열린 페이지는 60초마다 버전을 확인하며, 새 배포를 확인하면 새로고침합니다. 오프라인에서는 기존 화면을 유지합니다.

방문자의 화면에는 코드 편집 기능이 없습니다. 일정 수정은 GitHub 저장소에 쓰기 권한이 있는 사람이 수행합니다. 이 페이지는 로그인·초대 인증이 없는 일반 공유 페이지입니다. `noindex`는 검색엔진 색인 억제 요청이며 접근 제한이 아닙니다. 개인 예약번호나 여권·연락처를 넣지 마세요.
